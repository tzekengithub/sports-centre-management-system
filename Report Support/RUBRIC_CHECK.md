## Cells that are weaker than the rest (honest list)

- **Row 4, membership.py / coaching.py / billing.py** use the shared
  helpers `common.read_lines` / `append_line` / `rewrite_records` rather
  than calling `open()` themselves. This is the same pattern as the
  teacher's example (modules call a shared storage helper). Only
  booking.py (`save_day_sheet`) and `common.py` call `open()` directly.
  If the marker wants `open()` in every module file this would need a
  separate decision by the group.
- **Row 13, `else` / `finally`:** `finally` appears only in booking.py,
  where it is genuinely needed (closing the day-sheet file). The other
  modules use `else` but no `finally`, because their file closing happens
  inside `common.write_lines` (which has its own `finally`).
- **Row 13, shared handlers:** most membership / billing buttons are
  built by `common.build_pick_page` / `build_manage_page`, so the visible
  `try/except` for those buttons is in common.py, with the module
  supplying only the `raise ValueError` side.
- **Row 15:** the multi-line `#` block counts above come from the scan
  (two or more comment-only lines in a row, banner rules excluded).
